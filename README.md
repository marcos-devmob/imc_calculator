# FitCalc

Um aplicativo de cálculo de **IMC (Índice de Massa Corporal)** feito em **Flutter**, permitindo calcular o IMC de forma rápida e receber a classificação de peso correspondente.

## Funcionalidades

- Inserção de peso (kg) e altura (cm).  
- Cálculo instantâneo do IMC.  
- Classificação do IMC: abaixo do peso, peso ideal, acima do peso, obesidade (graus I, II e III).  
- Botão de reset para limpar os campos e reiniciar o cálculo.  
- Interface limpa, intuitiva e responsiva.

## Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/marcos-devmob/imc_calculator.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd FitCalc
   ```
3. Instale as dependências:
   ```bash
   flutter pub get
   ```
4. Rode o aplicativo:
   ```bash
   flutter run
   ```
Certifique-se de ter o Flutter e o Android/iOS o configurados corretamente no seu ambiente de desenvolvimento.
